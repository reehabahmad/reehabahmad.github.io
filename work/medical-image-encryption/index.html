3D colour medical image encryption

A 3D hyperchaotic map, an S-box and a discrete wavelet transform for secure colour medical image encryption.

Method

  1. 3D hyperchaotic map
  2. Permutation
  3. Diffusion
  4. S-box
  5. DWT

Medical images have strong correlations between neighbouring pixels, which an encryption scheme has to destroy thoroughly. A 3D hyperchaotic map drives permutation (shuffling pixel positions) and diffusion (changing pixel values, strengthened with an S-box), followed by a discrete wavelet transform. Chaotic systems are extremely sensitive to initial conditions, which gives a very large key space.
